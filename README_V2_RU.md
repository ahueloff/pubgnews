# PUBG News Alerts 2.0 — тестовая надстройка

## Что делает эта версия
- Сохраняет старый `pubg_news.py` и использует его сборщики PUBG Official API, Weibo и pubg.plus.
- Добавляет чтение текста статьи по ссылке.
- Делает русский перевод через существующий `translate_to_russian`.
- При наличии `GEMINI_API_KEY` пробует бесплатный тариф Gemini; если ключа нет, сервис недоступен или исчерпан лимит — переключается на Free Mode.
- Создаёт PNG-инфографику через Pillow.
- Отправляет оригинальное изображение (если оно есть), инфографику и подробный текст в Telegram.
- Использует отдельный workflow только с ручным запуском.

## Установка в существующий репозиторий
Скопируйте новые файлы и папку workflow в корень репозитория, сохранив существующий `pubg_news.py`:

- `article_reader.py`
- `ai_analyzer.py`
- `infographic.py`
- `telegram_sender.py`
- `pubg_news_v2.py`
- `requirements-v2.txt`
- `.github/workflows/pubg-news-v2.yml`

Не заменяйте старый `pubg_news.py`, старый workflow или `requirements.txt`.

## Тестирование
1. Откройте GitHub → Actions.
2. Выберите `PUBG News Alerts V2 (manual test)`.
3. Нажмите `Run workflow`.
4. Проверьте Telegram и логи выполнения.

Тестовая версия использует те же `news_*.json` и `pubg_status_state.json`, чтобы не отправлять уже обработанные новости повторно. Сначала проверьте один ручной запуск.

## Секреты
Обязательные (уже должны существовать):
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Необязательный:
- `GEMINI_API_KEY` — ключ бесплатного тарифа Gemini, если он доступен вашему аккаунту. Без него используется Free Mode. Никаких ключей в код не записывайте.

## Важные ограничения первой тестовой версии
- Парсер старого проекта выдаёт заголовок, summary и изображение. Чтение полной статьи зависит от структуры страницы и может не сработать для некоторых публикаций.
- Free Mode — это автоматизированная структуризация и перевод, а не генеративная ИИ-модель. В сообщении это явно обозначается.
- Gemini free tier имеет квоты и условия, которые могут меняться. При ошибке используется Free Mode.
- Инфографика — краткая визуальная выжимка, не замена полному тексту.
- Weibo в старом парсере пока фильтруется только по ключевым словам техработ; этот модуль не меняет список источников.
- Workflow V2 пока запускается вручную. Не включайте расписание, пока не проверите несколько запусков.
- Старый код помечает новость обработанной даже при неудачной отправке Telegram. Перед включением V2 на постоянное расписание нужно отдельно исправить и протестировать механизм повторной доставки.
